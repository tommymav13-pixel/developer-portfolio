# Philosophy

## Why I Build

I enjoy solving complex problems through structured thinking and continuous
learning.

Software engineering allows me to combine analytical thinking, creativity,
and lifelong learning into one profession.

---

# Learning Philosophy

I believe understanding is more valuable than memorization.

Whenever possible, I prefer to understand why something works before trying
to remember the syntax.

---

# Development Principles

- Build consistently.
- Document everything.
- Learn by doing.
- Finish what you start.
- Improve a little every day.
- Prefer clarity over cleverness.

---

# Documentation

Good documentation is part of good software.

I maintain documentation not only for others, but also to improve my own
understanding and create a reliable knowledge base.

---

# Version Control

I treat Git as part of the development process, not as a backup system.

Small commits with meaningful messages help document the evolution of a
project.

---

# Code Quality

My goal is to write code that is:

- Readable
- Maintainable
- Simple
- Well documented

Correctness comes first. Optimization comes later.

---

# Long-Term Goal

I am building a strong technical foundation that will enable me to grow from
junior software engineer to DevOps Engineer and ultimately to Quantitative
Developer.

I see software engineering as a lifelong learning journey.

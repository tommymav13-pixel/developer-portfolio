# Developer Handbook

## Overview

The Developer Handbook is a personal technical reference that documents
the tools, workflows, conventions, and development practices I learn and
use during my transition into software development.

The repository serves both as a learning resource and as practical
documentation for recurring development tasks.

## Purpose

The project is intended to:

- document technical knowledge in a structured way;
- create reusable references for development workflows;
- reinforce concepts by explaining them in my own documentation;
- establish consistent conventions for future projects;
- track the development of my technical workflow.

## Current Topics

The handbook currently contains documentation about:

- Git and GitHub;
- PowerShell;
- Python;
- VS Code;
- development workflows;
- naming and repository conventions;
- Markdown documentation.

## Skills Demonstrated

Through this project I am developing and demonstrating experience with:

- Git version control;
- GitHub repository management;
- technical documentation;
- Markdown;
- PowerShell workflows;
- repository organization;
- development conventions.

## Status

**Active**

The handbook is continuously expanded as I learn new tools, workflows,
and software engineering practices.

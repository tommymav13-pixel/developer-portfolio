My portfolio currently contains a combination of:

Learning repositories

Independent applications

The objective is to progressively increase the proportion of independently
designed software.

Future projects are expected to demonstrate increasingly advanced skills in

- Python application development;

- numerical computing;
- data processing;
- mathematical programming;
- quantitative development.

Projects will be added when there is sufficient implementation to provide
meaningful evidence of technical development.

# Technical Reading List

This reading list supports my development from Python fundamentals toward
professional software development, DevOps, data engineering, and quantitative
software development.

Books are prioritized by learning value rather than collected as a list of
resources.

Reading status is independent from ownership status.
A book may be owned while still marked as `planned` or `reference`.

---

## Status

| Status      | Meaning                                |
| ----------- | -------------------------------------- |
| `reading`   | Currently reading or actively studying |
| `next`      | High-priority next book                |
| `planned`   | Intended for a later learning phase    |
| `reference` | Used primarily as a reference work     |
| `completed` | Completed                              |

## Reading Principle

The objective is not to complete as many books as possible.

A technical book should result in one or more of the following:

- improved understanding;
- working code;
- exercises;
- notes;
- a portfolio project;
- a reusable development convention;
- improved problem-solving ability.

Reading supports development; it does not replace programming practice.

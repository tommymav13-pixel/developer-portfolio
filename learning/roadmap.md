# Learning Roadmap

This roadmap outlines my development from programming fundamentals toward
professional software development and, in the long term, quantitative
development.

The roadmap combines software engineering, computer science, mathematics,
and systems knowledge. These areas are developed in parallel rather than
as a strictly sequential path.

The roadmap will evolve as my knowledge, experience, and professional
direction develop.

## Roadmap Principle

The roadmap defines direction, not a requirement to study every topic
simultaneously.

Current learning priorities remain deliberately limited. New
technologies and subjects become active when the required foundations
are sufficiently developed or when a practical project creates a
reason to introduce them.

Progress should increasingly be demonstrated through:

- working software;
- exercises and problem solving;
- independent projects;
- tests;
- technical documentation;
- GitHub repositories;
- applied mathematical and quantitative work.
